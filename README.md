# ☕ Krishna Cafe

A modern, responsive café website built for **Krishna Cafe** with an attractive user interface, interactive menu, customer reviews, career applications, and a mobile-friendly experience.

🌐 **Live Website:** https://krishna-cafekanigiri.vercel.app/

---

## ✨ Features

- 🏠 Modern Home Page
- 📱 Fully Responsive Design
- ☕ Interactive Food & Beverage Menu
- 🖼️ Café Image Gallery
- ⭐ Customer Reviews
- ❤️ Like / Unlike Reviews
- 🕒 Review Date & Time
- 👤 Customer Profile Icons
- 💼 Careers Section
- 📝 Online Job Application
- 📲 WhatsApp Job Applications
- 📊 Google Analytics Integration
- 🔒 MongoDB Review Storage
- ⚡ Fast and lightweight frontend
- 🎨 Modern café-themed UI

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- dotenv

### Deployment

- Vercel — Frontend
- Render — Backend
- MongoDB Atlas — Database
